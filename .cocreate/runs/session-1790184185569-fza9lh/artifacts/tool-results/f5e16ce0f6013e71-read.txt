 48	
 49	**Highest-risk surfaces before client delivery:**
 50	1. **Run approval lifecycle** — no timeout on PENDING_APPROVAL; runs can hang indefinitely. ([§6](#6-execution-pipeline))
 51	2. **Log/event retention** — `TerraformRunLog`, `TerraformK8sEvent`, `TerraformPodStatus` have no cleanup job; unbounded growth. ([§7](#7-background-jobs--schedulers))
 52	3. **Drift scanning** — `TerraformProjectSyncStatus.nextScanAt` is populated but no cron reads it; scans are **webhook-only**. ([§8](#8-webhook-flow))
 53	4. **License tier gating** — `middleware.ts:78` enforces `PROFESSIONAL` minimum for `/api/terraform/**`, which may differ from the tier matrix in `lib/licensing/tier-limits.ts`. ⚠ ([§10](#10-configuration))
 54	5. **Editor sessions** — no stale-session cleanup; `ACTIVE` sessions could accumulate. ([§9](#9-editor--ai-subsystem))
 55	6. **AI chat tool calls** — no visible rate limit or max-time budget; runaway agents could exhaust tokens. ([§9](#9-editor--ai-subsystem))
 56	7. **Webhook replay** — HMAC signature verified, but no `deliveryId` dedup table observed. ([§8](#8-webhook-flow))
 57	8. **Zero Playwright e2e coverage** for Terraform despite full E2E infra in place. ([§13](#13-existing-test-coverage))

118	## 4. API layer
119	
120	Base path: `/api/terraform/**`. All routes require `NextAuth` session **except** webhook + state-import upload (explicit carve-outs in `middleware.ts:18-19`).
121	
122	Error model is consistent: unauthenticated → 401; forbidden (license, role, approver) → 403; resource missing or cross-org → 404; state conflict (drift, variable sync, lock, not-in-approval-state) → 409; invalid input (Zod) → 400.
