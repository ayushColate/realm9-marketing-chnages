 34	
 35	| Metric | Count |
 36	|---|---|
 37	| UI pages under `app/terraform/**` | 19 |
 38	| API route files under `app/api/terraform/**` | ~82 |

 42	| Background schedulers touching Terraform | 3 (+ startup recovery) |
 43	| K8s init containers in a full policy-enabled run | up to 5 (git-clone, TruffleHog, Checkov, Trivy, custom, policy-aggregate) |
 44	| Cloud providers with real support | AWS, Azure, on-prem (Proxmox + vSphere) |
 45	| Git providers with real support | GitHub, GitLab |
 46	| Existing automated tests (Jest) | 71 unit + 20 integration |
 47	| Existing Playwright e2e coverage for Terraform | **0** ⚠ |
 48	
 49	**Highest-risk surfaces before client delivery:**
 50	1. **Run approval lifecycle** — no timeout on PENDING_APPROVAL; runs can hang indefinitely. ([§6](#6-execution-pipeline))
 51	2. **Log/event retention** — `TerraformRunLog`, `TerraformK8sEvent`, `TerraformPodStatus` have no cleanup job; unbounded growth. ([§7](#7-background-jobs--schedulers))
 52	3. **Drift scanning** — `TerraformProjectSyncStatus.nextScanAt` is populated but no cron reads it; scans are **webhook-only**. ([§8](#8-webhook-flow))
 53	4. **License tier gating** — `middleware.ts:78` enforces `PROFESSIONAL` minimum for `/api/terraform/**`, which may differ from the tier matrix in `lib/licensing/tier-limits.ts`. ⚠ ([§10](#10-configuration))
 54	5. **Editor sessions** — no stale-session cleanup; `ACTIVE` sessions could accumulate. ([§9](#9-editor--ai-subsystem))
 55	6. **AI chat tool calls** — no visible rate limit or max-time budget; runaway agents could exhaust tokens. ([§9](#9-editor--ai-subsystem))
 56	7. **Webhook replay** — HMAC signature verified, but no `deliveryId` dedup table observed. ([§8](#8-webhook-flow))
 57	8. **Zero Playwright e2e coverage** for Terraform despite full E2E infra in place. ([§13](#13-existing-test-coverage))

118	## 4. API layer
119	
120	Base path: `/api/terraform/**`. All routes require `NextAuth` session **except** webhook + state-import upload (explicit carve-outs in `middleware.ts:18-19`).
121	
122	Error model is consistent: unauthenticated → 401; forbidden (license, role, approver) → 403; resource missing or cross-org → 404; state conflict (drift, variable sync, lock, not-in-approval-state) → 409; invalid input (Zod) → 400.

218	### 4.9 State import
219	
220	- `POST /api/terraform/workspaces/[id]/state-import/token` — generates token, hashes it (SHA-256), stores `stateImportToken` (hash), sets expiry and `stateImportStatus=PENDING`.
221	- `POST /api/terraform/state-import/upload` — **no NextAuth**, validates `X-Import-Token` header against stored hash + expiry. Uploads to S3/Azure under `imports/{workspaceId}/terraform.tfstate`. Transitions workspace `stateImportStatus=UPLOADED`. CSRF-exempt.

344	### 6.2 Block conditions at `POST /api/terraform/runs`
345	
346	All return HTTP **409** with a `code` field for the UI to route:
347	- `DRIFT_DETECTED` — `project.status === 'DRIFT_DETECTED'`
348	- `VARIABLES_PENDING` — `project.status === 'VARIABLES_PENDING'`
349	- `WORKSPACE_NEEDS_SYNC` — `workspace.variablesSyncStatus === 'NEEDS_SYNC'`
350	- `PENDING_INPUT` — `workspace.variablesSyncStatus === 'PENDING_INPUT'`
351	
352	### 6.3 K8s job anatomy
353	
354	Namespace: `terraform-runs`. Service account: `terraform-executor` (IRSA-annotated).
355	
356	Init containers (in order, if policy profile enables scanner):
357	1. `git-clone` (alpine/git) — checks out `gitRepoUrl` at `gitCommitSha || gitBranch`
358	2. `trufflehog` (trufflesecurity/trufflehog)
359	3. `checkov` (bridgecrew/checkov)
360	4. `trivy` (aquasec/trivy)
361	5. (optional) `custom-scanner` — user image with registry-creds-secret
362	6. `policy-aggregate` (alpine:3.19) — merges scan JSON, writes `/scan-results/policy-results.json`, evaluates `enforcementMode` + `blockOn*` → either proceeds or short-circuits
363	
364	Main container:
365	- `hashicorp/terraform:1.6` — runs `terraform init` (with backend override), `terraform plan`/`apply`/`destroy` depending on `RUN_TYPE` env var.
366	- Backend override file written by init: S3 or Azure blob backend stanza derived from project config (`backendType`, `stateBucket`, `azureResourceGroup`, etc.).
367	- AWS: uses `AWS_PROFILE` pointing at injected `~/.aws/credentials` with STS assumed-role credentials (short-lived) OR IRSA token.
368	- Azure: uses `ARM_USE_OIDC=true` + projected SA token OR client-secret from secret.
369	
370	Resource limits (defaults, overridable at workspace):
371	- requests: 256Mi memory / 250m CPU / 1Gi ephemeral
372	- limits: 2Gi memory / 1000m CPU / 5Gi ephemeral
373	- workspace volume: 2Gi emptyDir
374	- scan-results volume: 500Mi emptyDir
375	
376	Timeouts:
377	- pod scheduling: **5 min** before `ExecutionController` gives up
378	- job activeDeadlineSeconds: **1800 s (30 min)**
379	- job TTL after finished: **3600 s (1 h)** (K8s TTL controller)
380	
381	### 6.4 Monitoring loop (in `ExecutionController.executeWithMonitoring`)
382	
383	- every 3 s: fetch K8s events for job+pod, dedup by eventUid → `TerraformK8sEvent`
384	- every 5 s: fetch pod logs incrementally (track offset per container) → `TerraformRunLog`, mask credentials via `lib/terraform/utils/log-masking.ts`
385	- every 5 s: poll job status (`Job.status.succeeded|failed|active`)
386	- cancellation detected if pod disappears for 3 consecutive polls → throws `K8S_JOB_FAILED {cancelled:true}` → status CANCELLED
387	
388	### 6.5 Completion dispatch (`onRunCompleted`)
389	
390	- `PLAN → PLANNED`: if `project.autoApply` and plan exited cleanly, spawn APPLY run.
391	- `APPLY → APPLIED`: sets `EnvironmentWorkspace.provisioningStatus=PROVISIONED` / `BookingWorkspace.provisioningStatus=PROVISIONED`; recalculates env-level `Environment.provisioningStatus`.
392	- `DESTROY → DESTROYED`: snapshots workspace state into `Booking.workspaceSnapshots`; sets `DESTROYED`.
393	- Any `FAILED` / `POLICY_FAILED`: fires `sendTerraformRunNotification` + `sendEnvironmentProvisioningFailureNotification`.

471	### 8.1 Signature verification (GitHub)
472	
473	`app/api/terraform/webhooks/github/route.ts:13-21`:
474	
475	```ts
476	function verifyGitHubSignature(payload, signature, secret) {
477	  const hmac = crypto.createHmac('sha256', secret)
478	  const digest = 'sha256=' + hmac.update(payload).digest('hex')
479	  return crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(digest))
480	}
481	```
482	
483	- Header: `x-hub-signature-256`, format `sha256=<hex>`.
484	- Event header: `x-github-event`; only `push` is processed.
485	- Delivery header: `x-github-delivery` (used in audit log; **not** stored for dedup).

487	### 8.2 Drift detection classification
488	
489	`lib/terraform/services/drift-detection.service.ts:53-329`:
